## bluefin-cli sunset

Change the theme and wallpaper at sunrise and sunset

### Synopsis

Automatically switch between light and dark themes and different wallpapers based on sunrise and sunset times for your location.

```
bluefin-cli sunset [flags]
```

### Options

```
      --day-wallpaper string     Path to the day wallpaper image
      --enable                   Enable or disable sunset switching
  -h, --help                     help for sunset
      --latitude float           Latitude for solar calculations
      --longitude float          Longitude for solar calculations
      --night-wallpaper string   Path to the night wallpaper image
      --wallpaper-theme string   Theme for monthly wallpapers (bluefin, aurora, bazzite)
```
