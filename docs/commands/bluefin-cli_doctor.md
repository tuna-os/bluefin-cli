## bluefin-cli doctor

Find common problems in your setup of Bluefin CLI

```
bluefin-cli doctor [flags]
```

### Options

```
      --bench   Benchmark interactive shell startup vs a bare shell
      --fix     Apply safe automatic fixes before reporting
  -h, --help    help for doctor
```
