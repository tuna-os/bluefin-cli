## bluefin-cli

CLI tool for Homebrew and shell setup

### Synopsis

Bluefin CLI brings the bluefin terminal experience to you.

- Homebrew & Tool Management
- Shell Environment Configuration
- System Status & MOTD
- Starship Theme Management
- Sunset themes and wallpapers
- Automated Font Installation
- Monthly Wallpaper Themes

```
bluefin-cli [flags]
```

### Options

```
  -h, --help   help for bluefin-cli
```
